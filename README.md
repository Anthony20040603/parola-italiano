# Parola

一个适合手机使用的意大利语单词卡网页。它在浏览器本地读取 MDict `.mdx` 词库，使用系统语音朗读意大利语，并在当前设备保存学习进度。

## 当前简单版

- 导入标准 MDict 1.x / 2.0 `.mdx` 文件
- 从词库中读取最多 7000 个适合学习的意大利语词条
- 查看释义、标记“还不熟”或“认识了”
- 不熟的词会在后续几张卡片中再次出现
- 使用浏览器的意大利语语音朗读
- 在 IndexedDB 保存当前词库，在 localStorage 保存进度

## GitHub Pages

发布目录是 `dist`。词库文件不会放入仓库，使用者需要在自己的设备上导入一次。

## 隐私说明

导入的 MDX 文件只在浏览器本地读取和保存，不会上传到网站服务器。不同设备之间不会同步进度。
