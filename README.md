# Parola

一个适合手机使用的意大利语单词卡网页。它在浏览器本地读取 MDict `.mdx` 词库，使用系统语音朗读意大利语，并用 FSRS-6 安排复习。

当前版本：`v1.4.0`。目前所有功能迭代都属于 V1 系列，详细记录见 [CHANGELOG.md](CHANGELOG.md)。

## 当前功能

- 导入标准 MDict 1.x / 2.0 `.mdx` 文件
- 从词库中读取最多 7000 个适合学习的意大利语词条
- 两种题型：看意大利语回忆中文、看中文拼写意大利语
- 拼写时忽略大小写；只缺少重音符号会提示正确写法，但不判错
- 每次作答使用“忘了 / 勉强想起 / 正常想起 / 非常熟练”四档评分
- 使用 FSRS-6 根据同一套熟练度状态安排两种题型的下次复习
- 新词先学习释义，约 10 分钟后安排第一次拼写；以后两种题型交替出现
- 可以设置每日新词数、每日复习数和目标记忆率
- 完成每日任务后可追加“学习 5 个新词”混合轮次（新旧词交替）或“复习一下”（最多 10 个薄弱旧词）；追加额度只在当天有效
- 词库进度页可搜索、筛选和排序全部单词，并查看最近评分、题型练习次数和预计下次复习时间
- 为每个词库生成固定的乱序种子，重新打开后保持相同学习顺序
- 使用浏览器的意大利语语音朗读
- 在 IndexedDB 保存当前词库和完整进度，并为较小进度保留 localStorage 兼容副本
- 将进度导出为 JSON 文件，并在其他设备导入恢复；文件包含固定乱序种子、FSRS 卡片状态、每日计数、设置和复习日志
- 自动迁移旧版进度文件和浏览器内旧进度

## GitHub Pages

发布目录是 `dist`。词库文件不会放入仓库，使用者需要在自己的设备上导入一次。

## 版本管理

- `v1.0.0`：可用的第一版
- `v1.1.0` 至 `v1.4.0`：V1 系列的功能更新
- 后续小修复递增末位版本号，例如 `v1.4.1`
- 后续新增较完整的功能递增中间版本号，例如 `v1.5.0`

每个已发布版本都使用 Git 标签保存，因此可以在本地或 GitHub 上准确查看和恢复，不需要另外复制一套源代码文件夹。

## 隐私说明

导入的 MDX 文件只在浏览器本地读取和保存，不会上传到网站服务器。不同设备之间不会自动同步进度，但可以通过导出、导入 JSON 进度文件手动迁移。

## 调度说明

项目使用 `ts-fsrs` 5.4.2 的 FSRS-6 实现。两种题型共用一张 FSRS 卡片，所以不会产生两套互相冲突的复习日期；题型完成情况和错误次数则单独记录，用来决定下次展示哪种题。

## 本地检查

运行 `node tools/test.mjs` 可以检查 FSRS 基本间隔、重音宽容规则和页面依赖顺序；运行 `node tools/serve.mjs` 可启动本地预览。
